# AERO-BLS

**Turbulent boundary layer separation and drag reduction on NACA airfoils** — a reproducible 2D RANS study (OpenFOAM v2412, k-ω SST) of NACA 0012/2412/4412 at Re = 10⁵–10⁶.

The full project — pipeline scripts (00–08), LaTeX paper, conference poster, validation data, and results — lives in [`projects/AERO-BLS/`](projects/AERO-BLS/). See its [README](projects/AERO-BLS/README.md) for the reproduction guide.

Development happens on the `vibe/cfd-naca-bls-ea5ba1` branch (draft PR).
